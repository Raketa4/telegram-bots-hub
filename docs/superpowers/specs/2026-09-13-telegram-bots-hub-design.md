# telegram-bots-hub: дизайн

Дата: 2026-09-13

## Цель

Одностраничный статический сайт с 10 кнопками. Каждая кнопка в будущем
будет вести на отдельного обучающего Telegram-бота. Сайт создаётся
заранее, боты — по мере обучения, добавляются в конфиг без переделки
разметки.

## Архитектура

- Чистый HTML/CSS/JS, без сборки и фреймворков.
- Список кнопок вынесен в конфиг `js/bots.js`:

  ```js
  const BOTS = [
    { id: 1, title: "Кнопка 1", username: null },
    ...
    { id: 10, title: "Кнопка 10", username: null },
  ];
  ```

- `js/main.js` рендерит карточки кнопок по `BOTS` в контейнер на странице.
  - `username === null` → кнопка неактивна (disabled), серая, подпись «скоро».
  - `username` задан → кнопка становится ссылкой `<a href="https://t.me/<username>" target="_blank" rel="noopener">`.
- Добавление бота = правка одной строки в `js/bots.js`, без изменения HTML/CSS.

```
telegram-bots-hub/

```

## Деплой

Новый GitHub-репозиторий `Raketa4/telegram-bots-hub`, публикация через
GitHub Pages из ветки `main` (корень). Итоговый адрес:
`https://raketa4.github.io/telegram-bots-hub/`.

## Тестирование

Ручная проверка в браузере: все 10 кнопок отрисованы, неактивные визуально
отличаются от активных, замена `username: null` на реальный юзернейм в
конфиге превращает кнопку в рабочую ссылку без правок HTML/CSS.

## Вне рамок

- Никакого backend/webhook — кнопки только открывают `t.me/<bot>`.
- Логика самих Telegram-ботов — отдельные проекты, вне этого репозитория.
